# DevLibrary: правила проекта и учебных материалов

Перед созданием или обновлением курсов прочитай [правила подготовки материалов](docs/ai-course-rules.md) и [инструкцию для агентов](docs/agent-guide.md). На сайте инструкция доступна по `/agents`, текстовая версия — `/llms.txt`. Используй образцы из `templates/`; готовый запрос для ИИ — `templates/ai-authoring-prompt.md`.

Для собственного курса доступны [руководство](docs/custom-courses.md), заготовка `templates/course-folder/` и команда `pnpm course:create --title "Мой курс" --path ./templates/course-folder --data-dir ./library-data`. Указывай хранилище явно; относительные пути считаются от рабочей папки команды.

- Это учебная платформа с файловым хранилищем, которую каждый пользователь запускает в собственной копии локально или в Docker. Работай только в выбранной библиотеке пользователя; сохраняй её существующие ID курсов и уроков, оригиналы, прогресс и резервные копии. Работай через интерфейс/API своей копии сайта или `createLibraryStore` с явно выбранным `DEVLIBRARY_DATA_DIR`, а не прямую перезапись JSON пользователя. Для новой пустой библиотеки используется `DEVLIBRARY_SEED=empty`; настройка не должна очищать существующие данные.
- Путь при импорте относится к файловой системе сервера. Не обходи ограничения путей и проверку происхождения запросов ради автоматизации. С телефона и другого компьютера пользователь может писать конспекты через редактор сайта. Не включай личные курсы, прогресс и резервные копии в переносимую версию приложения.
- Используй pnpm для зависимостей и команд проекта. Не смешивай lock-файлы разных менеджеров.
- Используй направления из `lib/course-sections.mjs`. Язык программирования для времени и язык текста RU/EN — разные поля.
- Урок завершается после ручной отметки просмотра видео и подтверждённого чтения. Теоретический тест необязателен: его отсутствие, пропуск или ошибка не блокируют завершение. Не подменяй тест ручным `passed`, не начисляй XP повторно и не создавай фиктивную активность.
- Подключай видео и вопросы к реальному ID урока в `data/lesson-learning.ts`. Архив или папка не являются видео. Ссылки, таймкоды, расшифровки и результаты проверки должны иметь реальные источники.
- Сохраняй порядок вопросов и вариантов в опубликованных тестах: сохранённые ответы имеют позиционные индексы, а сервер пересчитывает результат по текущим ключам. Изменение смысла теста требует продуманного переноса его прогресса.
- Для проверки завершений и проектов используй изолированный `DEVLIBRARY_DATA_DIR` или чистые функции. Не заполняй настоящий прогресс пользователя тестовыми результатами.
- После изменений приложения выполняй подходящие тесты, проверку типов, lint и сборку. Для текстовой правки проверяй итоговое содержание и ссылки без лишних проверок.
