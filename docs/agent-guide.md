# Как работать с DevLibrary через ИИ-агента

Эта инструкция доступна на сайте по адресу `/agents`; краткая текстовая версия для агентов — `/llms.txt`. Открой `/agents`, чтобы скопировать готовый запрос и перейти к созданию курса.

## Пользователю

1. Определи название курса, свой уровень, желаемый результат и доступные источники.
2. Передай агенту адрес `/agents` своего сервера. Агенту с локальным проектом передай `AGENTS.md` и `docs/ai-course-rules.md`.
3. Попроси сначала предложить программу, затем подготовить один полный урок. Проверь результат перед наполнением всего курса.
4. В разделе **Управление библиотекой → Добавить курс → Написать на сайте** создай курс и вставь Markdown или выбери файл `.md` / `.markdown` / `.txt` до 2 МБ со своего устройства. Проверь текст в редакторе и сохрани его. Для следующих уроков используй **Добавить тему**.

Редактор работает в браузере другого компьютера или телефона. При импорте папок путь относится к устройству, на котором запущен сервер. Локальный путь телефона или другого компьютера сам по себе серверу недоступен. Доступные способы импорта зависят от режима запуска.

Готовая [папка-заготовка](../templates/course-folder/Notes/01-introduction/README.ru.md) содержит первый урок на RU/EN. Подробнее о способах создания — в [руководстве по своим курсам](custom-courses.md).

Для создания из командной строки в папке проекта:

```sh
pnpm course:create --title "Мой курс" --note ./lesson.md --language ru --data-dir ./library-data
```

Для импорта готовой папки:

```sh
pnpm course:create --title "Мой курс" --path ./templates/course-folder --data-dir ./library-data
```

Относительные пути считаются от текущей рабочей папки. Для новой пустой библиотеки заранее задай переменную окружения `DEVLIBRARY_SEED=empty` и используй новый каталог `--data-dir`.

## Агенту

Каждый пользователь запускает собственную копию приложения со своим хранилищем. Работай только в выбранной библиотеке пользователя. Не обходи ограничения путей и проверку происхождения запросов. Не передавай секреты через URL, тексты уроков и отчёты.

Сначала прочитай `AGENTS.md`, [правила курсов](ai-course-rules.md), схему `lib/catalog.ts`, реестр `data/lesson-learning.ts` и [шаблон запроса](../templates/ai-authoring-prompt.md). Перед изменением приложения прочитай документацию установленного Next.js в `node_modules/next/dist/docs/`.

Создавай курсы через редактор или существующий Store/API. На сервере `createLibraryStore` из `lib/local-library.mjs` должен получать явно выбранный `DEVLIBRARY_DATA_DIR`. Для новой пустой библиотеки используется `DEVLIBRARY_SEED=empty`; существующую библиотеку эта настройка не очищает. Не включай чужие курсы, прогресс и резервные копии в переносимую версию приложения. Не переписывай `library.json` и `progress.json` вручную.

Методы Store: `catalog()`, `createCourse(input)`, `importCourse(input)`, `addNote(courseId, note)`, `note(lessonId, language)`, `saveNote(lessonId, language, text, hash)`. Для обновления файлового курса существует `refreshCourse(courseId)`.

В браузере используй запросы к тому же адресу своей копии сайта:

| Операция | Запрос |
| --- | --- |
| Каталог и реальные ID | `GET /api/library` |
| Создать курс | `POST /api/library`, JSON: `action: "create"`, `title`, `category`, `difficulty`, необязательный `note` |
| Добавить тему | `POST /api/library`, JSON: `action: "add-note"`, `id` курса, `note` |
| Прочитать исходный текст | `GET /api/library?action=note&id=<lessonId>&language=ru` |
| Сохранить текст | `POST /api/library`, JSON: `action: "save-note"`, `id` урока, `language`, `text`, полученный `hash` |

Объект `note` содержит `title`, `language` (`ru` или `en`) и `text` в Markdown. После создания курса прочитай возвращённый `id`; после добавления темы — `lessonId`. При конфликте `409` прочитай актуальный текст и объедини правки; не подменяй хеш для принудительного сохранения.

Если нет доступа к приложению, выдай текст для вставки и прямо сообщи, что он ещё не сохранён.

## Материалы

```text
Мой курс/
  Notes/
    01-Введение/
      README.ru.md
      README.en.md
    02-Практика/
      README.ru.md
```

Английский файл добавляй только с полноценным переводом. Оглавление, которое не должно становиться уроком, начинай с `<!-- devlibrary:index -->`. Используй категории из `lib/course-sections.mjs` и метаданные по [шаблону курса](../templates/course.json).

Каждый урок содержит цель, предварительные знания, объяснение своими словами, рабочий пример с ожидаемым результатом, типичную ошибку, упражнение и источники. Не называй текст расшифровкой видео, если видео не просмотрено и нет расшифровки. Не придумывай источники и таймкоды. Архив не является видео.

Видео и необязательные тесты подключаются к реальному ID урока в `data/lesson-learning.ts`. Изменение реестра требует пересборки приложения. Шаблоны JSON не импортируются автоматически. Опубликованные вопросы и ответы сохраняют порядок и смысл: прогресс хранит позиционные индексы; перевод RU/EN должен сохранять ID и правильные индексы.

## Сохранность и проверка

Сохраняй существующие ID, пользовательские исходники, прогресс и резервные копии. Не отмечай материалы пройденными за пользователя и не создавай фиктивные часы или XP. Новое завершение требует ручной отметки просмотра назначенного видео и подтверждения чтения; тест необязателен, проходной результат самопроверки — 80%.

Для проверок используй временную изолированную `DEVLIBRARY_DATA_DIR`. После изменения приложения выполни `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm build`. Проверь реальное отображение материалов, ссылки, код и переводы. Для одной текстовой правки достаточно проверить текст и ссылки.

В отчёте укажи добавленные и действительно сохранённые материалы, источники, выполненные проверки и недостающие данные.
