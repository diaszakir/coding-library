# Собственные курсы

Каждый человек запускает свою локальную копию DevLibrary и хранит свою библиотеку. Аккаунт не нужен. Курсы другой установки автоматически не подключаются.

## Через сайт

Открой **Управление библиотекой → Добавить курс → Написать на сайте**. Укажи название, напиши первый конспект или выбери файл `.md`, `.markdown`, `.txt` до 2 МБ. Текст файла появится в редакторе; проверь его и нажми **Создать курс**. Можно создать пустой курс, а затем добавлять темы и менять оформление.

Выбор файла работает на устройстве с браузером. **Из папки** открывает папки компьютера, где запущен сервер; в Docker это папки внутри контейнера. Для переноса одного конспекта с другого устройства используй выбор файла в редакторе.

## Структура готового курса

Скопируй `templates/course-folder` в отдельную папку и замени пример своими материалами:

```text
my-course/
  Notes/
    01-introduction/
      README.ru.md
      README.en.md
    02-next-topic/
      README.ru.md
      README.en.md
```

Одна папка темы — один урок. Русская и английская версии необязательны одновременно: достаточно одного языка. Номера в названиях папок задают порядок тем. Допустимы относительные ссылки на небольшие текстовые исходники рядом с конспектом. Видео, архивы и исполняемые файлы импорт не копирует.

Импортируй папку через сайт или CLI. Приложение создаст собственную копию. После импорта новые уроки можно добавлять через сайт либо в папке `courses/<id>/` внутри библиотеки с последующим **Обновить из файлов**. Не перезаписывай `library.json` вручную.

## Через CLI или ИИ-агента

В каталоге `site`:

```sh
pnpm course:create --title "Мой курс"
pnpm course:create --title "Мой курс" --note ./lesson.md --language ru
pnpm course:create --title "Мой курс" --path ./my-course
pnpm course:create --help
```

По умолчанию команда использует `DEVLIBRARY_DATA_DIR`, затем `dataDirectory` из `courses.config.json`, затем `./library-data` в каталоге проекта. В исходной установке сохранена настройка `../library-data`. Чтобы создать отдельную библиотеку, передай `--data-dir ./my-library`; для старта без встроенных курсов задай `DEVLIBRARY_SEED=empty` перед первым запуском этой библиотеки. Настройка наполнения не удаляет существующие курсы. После создания CLI напечатает ID курса, папку хранения и ссылку на его настройки. Метаданные можно изменить на сайте.

Команда работает через `createLibraryStore`: сохраняет идентификаторы, проверяет импорт, делает собственную копию исходников. Перед новой библиотекой проверь путь хранения. При запущенном сервере CLI и сайт должны использовать одну и ту же папку, иначе курс появится в другой библиотеке.

В Docker сначала скопируй готовую папку внутрь контейнера:

```sh
docker compose cp ./my-course devlibrary:/tmp/my-course
docker compose exec devlibrary node scripts/create-course.mjs --title "Мой курс" --path /tmp/my-course
```

Альтернативный способ без CLI — создать курс на сайте и вставить текст конспектов.

Для работы с агентом открой [инструкцию на сайте](/agents), [правила материалов](ai-course-rules.md) и [готовый запрос](../templates/ai-authoring-prompt.md). Попроси агента сначала подготовить структуру и тексты, затем импортировать их через Store или CLI в явно указанную библиотеку. Вопросы тестов и видео подключаются отдельно в `data/lesson-learning.ts` и требуют пересборки приложения.
